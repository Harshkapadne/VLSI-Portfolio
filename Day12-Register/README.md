# Day 12 - 4-bit Register with Synchronous Reset

## Objective
Design and verify a 4-bit register using Verilog.

## Concepts Learned
- 4-bit registers
- Synchronous active-high reset
- Positive-edge-triggered sequential logic
- Nonblocking assignments
- Testbench-based verification

## Files
- register_4bit.v: RTL design
- register_4bit_tb.v: Testbench

## Verification
Five test cases:
1. Synchronous reset
2. Capture 1010
3. Capture 0101
4. Hold output between rising clock edges
5. Capture 1111
